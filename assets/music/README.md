# Background music

Kuch bhi daalna zaroori nahi. Agar yahan koi track nahi hai to render service apna banaya hua
dark ambient music bed use karti hai (ffmpeg se synthesize, koi license ya Content ID ka issue nahi).

Apne tracks use karne ho to `.mp3` / `.wav` / `.m4a` files yahin daal do. Har video ke liye ek track
automatically chunha jata hai, uska volume apne aap voice ke neeche set hota hai aur bolte waqt dabta hai.

## Kahan se lein (commercial use, attribution nahi chahiye)
- **Mixkit** (mixkit.co/free-stock-music): free license, attribution nahi.
- **Pixabay Music**: free commercial use, attribution nahi. Dhyan: kabhi kabhi YouTube pe
  Content ID claim aa jata hai, to download ke waqt license page ka screenshot rakho.

Ye mat lo: YouTube Audio Library (license sirf YouTube ke liye hai, tumhara video IG/FB/X pe bhi jata hai),
Incompetech aur Bensound ka free tier (attribution zaroori hai).

## Kaisa track chunein
- Instrumental, koi vocals nahi, 60 sec ya usse lamba
- 70-95 BPM, kam dynamics (beech me bada drop ya loud hit nahi)
- Mood: dark ambient / documentary tension / news underscore / cinematic pulse
- Search words: "dark ambient", "documentary tension", "news underscore", "cinematic pulse"
